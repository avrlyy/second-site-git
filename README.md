# Зоомагазин «Лапки»

Одностраничный сайт зоомагазина с каталогом товаров и живым поиском по карточкам.

## О проекте
Сайт сверстан с использованием HTML, CSS (flexbox/grid, адаптивность) и JavaScript. 
Реализован живой поиск по товарам: при вводе текста карточки фильтруются в реальном времени.
